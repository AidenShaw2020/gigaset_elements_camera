# Original camera: GM8126 / Gen1

Status: **supported and hardware-validated**.

This is the original Gigaset/Y-cam model with an 8 MiB W25Q64FV SPI flash,
GM8126 SoC and MyLoader. The dump, patch, install, local web manager, password
reset and Home Assistant gateway paths were validated on two independent
cameras running firmware `1.10 (build 20140802)`.

Do not use these tools on the newer S30851-H2531-R101/Ambarella camera. That
model has a different SoC, boot chain and 128 MiB NAND layout.

## What the Gen1 path provides

- read-only SPI flash dump without desoldering;
- source-only MEF patching using firmware read from the user's own camera;
- local web dashboard, live view and motion-zone editor;
- configurable admin and root passwords;
- cloud disabled by default;
- authenticated Telnet;
- physical factory reset to DHCP and documented default credentials;
- optional multi-camera Home Assistant MQTT gateway.

No vendor firmware, dump, key, certificate, serial number or device
configuration is included in this repository.

## Hardware and host requirements

- 3.3 V USB-UART adapter connected to GND, RX and TX;
- camera Ethernet connected directly to the PC or to an isolated switch;
- Python 3.9 or newer;
- Windows: Npcap with raw-packet support;
- physical MAC address of the PC Ethernet adapter;
- camera MAC address from its label.

Never connect a 5 V UART signal or the adapter's VCC pin to the camera. Power
the camera from its normal supply.

Install the host requirements from the repository root:

```powershell
python -m pip install -r requirements.txt
```

## 1. Read a stock camera

Build the auditable 264-byte RAM payload:

```powershell
python .\build_payload.py
```

Connect UART at 115200 baud and run the raw-Ethernet dumper. It does not require
changing the PC adapter's IPv4 address:

```powershell
python .\bootloader_dump_raw.py `
  --host-mac 98:76:54:32:10:00 `
  --uart-port COM3 `
  --output camera-read-1.bin
```

Power-cycle the camera when prompted. Repeat the read independently:

```powershell
python .\bootloader_dump_raw.py `
  --host-mac 98:76:54:32:10:00 `
  --uart-port COM3 `
  --output camera-read-2.bin

Get-FileHash -Algorithm SHA256 .\camera-read-1.bin, .\camera-read-2.bin
```

Do not continue unless both files:

- are exactly 8,388,608 bytes;
- contain `GM8126` at offset 0;
- contain `MEF 7f` at offset `0x20000`;
- have identical SHA-256 hashes.

Keep both verified dumps offline. Generated `.bin`, `.mfw` and `.mef` files are
ignored by Git and must never be published.

## 2. Build the local-manager image

These commands use only the dump read from that camera:

```powershell
python .\firmware_tools\extract_mef.py `
  .\camera-read-1.bin .\camera-original.mef

python .\firmware_tools\patch_oncamera_manager.py `
  .\camera-original.mef .\camera-local-manager.mef `
  --mac 7C:2F:80:00:00:00

python .\firmware_tools\build_manager_flash.py `
  .\camera-read-1.bin .\camera-local-manager.mef `
  .\camera-local-manager-full.bin `
  --partition-output .\camera-local-manager-partition1.bin
```

The patcher prints the camera MAC, derived `admin` web password and default
`root:root` credentials. Save this output before installation.

## 3. Install only MyLoader partition 1

Prepare MyLoader through UART:

```powershell
python .\firmware_tools\uart_loader.py prepare --port COM3
```

In a second terminal, transfer the generated partition. MyLoader uses fixed IP
`192.168.168.1` and pre-Linux MAC `00:80:48:01:23:45`:

```powershell
python .\firmware_tools\raw_tftp_put.py `
  192.168.168.1 .\camera-local-manager-partition1.bin `
  --host-ip 192.168.168.2 `
  --host-mac 98:76:54:32:10:00
```

Wait for MyLoader's explicit verification result. Reboot only after `Done`:

```powershell
python .\firmware_tools\uart_loader.py finish --port COM3 --timeout 300
```

On first boot the camera uses DHCP. Defaults are:

- root/Telnet/UART: `root` / `root`;
- web user: `admin`;
- web password: derived locally from the camera MAC;
- vendor cloud/proxy: disabled and server blank.

The MAC-derived web password is:

```text
base64("LUCKOTVF" + reverse(MAC_without_colons) + "YCAMVF")
```

Change both passwords in the local web manager after installation.

## Factory reset

Holding the physical RESET button invokes the stock reset service. On the next
boot the manager restores DHCP, `root:root`, the MAC-derived admin password,
disabled cloud state and the local-manager web paths. This path was validated
on hardware, including the fallback used when the factory-default MTD archive
is empty.

## Cloudless manager without a firmware patch

To disable the retired cloud on a stock Gen1 camera without installing the
on-camera manager:

```powershell
python .\cloudless_manager.py --camera 192.168.1.50 --mac 00:11:22:33:44:55
```

The manager opens `http://127.0.0.1:8765/`, uses the stock backup/restore pages
and changes only the cloud-client configuration.

## Home Assistant

The optional add-on is described in the [repository README](../../README.md#home-assistant-add-on).
One instance supports multiple cameras and does not become a firmware
dependency.

## Recovery

Recovery uses the same MyLoader partition-1 workflow with a partition image
rebuilt from the camera's own double-verified dump. Never substitute a dump
from a different camera because it may contain device-specific data.
