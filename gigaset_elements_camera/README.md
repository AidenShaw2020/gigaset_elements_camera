# Gigaset elements camera local gateway

Optional, fully local Home Assistant bridge for discontinued Gigaset and Y-cam
cameras. GM8126/Gen1 is hardware-validated; the Ambarella S2L profile is
experimental. One add-on instance supports multiple cameras and provides MQTT
discovery, motion events, refreshable snapshots, diagnostic telemetry and an
authenticated MJPEG proxy. Cameras are managed through the add-on's visual web
editor, without YAML. See [DOCS.md](DOCS.md) for configuration and camera setup.
